# 🌌 Galaxy Morphological Classification with Deep Learning

## 📌 Project Overview

This project applies Deep Learning techniques to solve a multi-class image classification problem using galaxy imaging data. A Convolutional Neural Network (CNN) was developed to automatically classify galaxies into 10 morphological categories based on their visual features.

The main objective is to demonstrate practical skills in data preprocessing, model development, evaluation, and performance analysis using a real-world scientific dataset.

---

## 🎯 Objective

Build and evaluate a CNN model capable of accurately classifying galaxy morphologies while analyzing model strengths, weaknesses, and sources of misclassification.

---

## 🧠 Methodology

The workflow includes:

- 📥 Data loading and preprocessing  
- 🔄 Image normalization  
- ✂️ Train / validation split  
- 🏗 CNN architecture design  
- 🚀 Model training  
- 📊 Performance evaluation  
- 🔎 Confusion matrix analysis  
- ⚠️ Error interpretation  

---

## 🏗 Model Architecture

The model is based on a Convolutional Neural Network (CNN) including:

- Convolutional layers for feature extraction  
- Max-pooling layers for dimensionality reduction  
- Fully connected layers  
- Softmax activation for multi-class classification  

The model was trained to classify galaxies into 10 categories.

---

## 📊 Results

- ✅ **Overall Accuracy:** 0.80  
- 📈 Strong performance for galaxy types 2, 3, and 5  
- ⚠️ Lower performance in underrepresented classes due to class imbalance  
- 🔄 Misclassifications mainly driven by morphological similarities  

Both absolute and normalized confusion matrices were used to evaluate performance.

---

## 💡 Key Insights

- Class imbalance significantly affects classification performance  
- Morphologically similar classes increase model confusion  
- Higher-resolution data or transfer learning may improve results
